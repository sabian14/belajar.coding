Java Script

JavaScript adalah bahasa pemrograman yang digunakan untuk memberikan interaksi dan logika pada sebuah website. Dengan JavaScript, website tidak hanya menampilkan informasi secara statis, tetapi juga dapat merespons tindakan yang dilakukan oleh pengguna. Contohnya adalah ketika pengguna menekan tombol, JavaScript dapat menjalankan perintah tertentu, seperti menampilkan pesan, mengubah teks, mengganti warna, membuka menu, melakukan perhitungan, atau menjalankan animasi. JavaScript juga dapat digunakan untuk membuat berbagai aplikasi web sederhana hingga kompleks, seperti kalkulator, game, formulir interaktif, sistem login, dan berbagai fitur lainnya.


HTML

HTML, CSS, dan JavaScript adalah tiga teknologi yang sangat penting dalam pembuatan website. Ketiganya memiliki fungsi yang berbeda, tetapi saling berhubungan dan biasanya digunakan secara bersama-sama. Dengan menggunakan HTML, CSS, dan JavaScript, kita dapat membuat website yang memiliki struktur yang jelas, tampilan yang menarik, serta fitur yang dapat digunakan oleh pengguna.


CSS

CSS (Cascading Style Sheets) adalah bahasa yang digunakan untuk mengatur tampilan dari website yang telah dibuat menggunakan HTML. Dengan CSS, website yang awalnya terlihat sederhana dapat dibuat menjadi lebih menarik dan rapi. CSS dapat digunakan untuk mengatur warna teks, ukuran tulisan, jenis font, warna background, ukuran gambar, jarak antar elemen, posisi elemen, border, bayangan, hingga animasi. CSS juga dapat digunakan untuk membuat website menjadi responsif sehingga tampilannya dapat menyesuaikan dengan berbagai ukuran layar, seperti komputer, laptop, tablet, dan smartphone. Jika HTML adalah kerangka website, maka CSS dapat diibaratkan sebagai bagian yang memberikan desain dan mempercantik website tersebut.
